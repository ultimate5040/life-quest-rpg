# Lifeight v0.3 ・ HERO画面 仕様書

## 0. このドキュメントの目的

Claude（または他のLLM）に丸投げして、Lifeight v0.3 の HERO 画面を**単一HTML（CSS/SVGインライン、JSなし）**で出力してもらうための自己完結スペック。読めば他の資料を参照せず実装できる。

## 1. Lifeight とは

中学生〜30代男子向けの、人生RPG型・成長検定アプリ。
コンセプト：**勇者 × 本棚 × 八徳**。書を進めると徳が育ち、装備が手に入る。

v0.3 の HERO 画面は、**現代の自分をスキャナーで診断している**体験として設計する。

## 2. 守ること（3原則）

1. **戻った者を讃えよ** ・ 連続記録途切れに減点なし、再開を歓迎
2. **昨日の自分と比べよ** ・ 他人との比較・ランキングなし
3. **現実へ送り出せ** ・ 滞在を目的化しない、外への次の一歩を提示

## 3. 対象ユーザ

- 第一：中学生男子
- 第二：30代男子（両にらみ、ただしUIの密度は中学生基準）
- 使う場面：通学中、放課後、夜寝る前、週末の振り返り

## 4. 技術制約

- モバイル縦画面ファースト（iPhone 14 / 390×844 を基準）
- 単一HTML + インラインCSS/SVG、JSなし（静的モック）
- 外部フレームワーク禁止（React / Vue / Tailwind 等）
- フォントはシステムフォント + Google Fontsは使わない
- ライブラリ依存ゼロ

## 5. 設計哲学

> **Lifeight の HERO 画面は、"ゲームのキャラ画面"ではなく、"自己診断装置のディスプレイ"である。**
>
> スマホは、ユーザーが自分自身を**走査（スキャン）**するための装置。画面は診断結果を可視化している。ただし、冷たい医療機器ではなく、**祝祭的・煌めき**を持つ。結果として、八徳の数値が星のように舞う。

## 6. 世界観トーン

### 配合比
- 現代 80% × 微かな魔法 20%
- **硬派SF（Destiny/Cyberpunk）には振り切らない**
- **和風（和紙/墨/セピア）にも戻らない**
- 近未来的要素は **UI枠線・スキャン光線・粒子** に限定

### 参照作品
- 主：**学園アイドルマスター（学マス）** ・ グラスモーフィズム、フラット2.0、CMY配色
- 副：**原神「命ノ星座」** ・ 星座としてのステータス可視化
- 副：**Persona 5** ・ 情報階層、キャラ立ち絵の扱い
- 避ける：Destiny / Cyberpunk 2077 / NieR:Automata 系（硬派・無機質）

### 避ける
- 余白過多のWebダッシュボード感
- モノスペース数字だけに頼る
- 単色フラット背景
- 冷たい無機質なHUD

## 8. 画面構成（HERO）

### 8.1 全体レイアウト

モバイル縦 420px最大、以下の縦順：

1. ヘッダ（最小HUD）
2. **スキャンステージ**（画面の縦60%を占める最大フォーカス）
3. 八徳詳細カード 2列×4行
4. 装備 5スロット
5. 昨日の自分との比較
6. AIウィスパー
7. ボトムナビ（fixed）

### 8.2 背景

- ベース：`#0d1220` (深い夜の青黒)
- 上部グラデ：`radial-gradient(ellipse at 50% 0%, #1a2445 0%, transparent 60%)`
- 下部グラデ：`radial-gradient(ellipse at 50% 100%, #2a1245 0%, transparent 60%)`
- 粒子：固定配置の微小な白点を20〜30個、opacity 0.3〜0.8で散らす（星空感）
- 全体に`backdrop-filter: blur`不使用（ベースは素通し、パネル側でかける）

### 8.3 ヘッダ

高さ48px程度、以下を横並び：
- 左：ブランド `LIFEIGHT`（letter-spacing: 0.3em, 14px, サンセリフ太字）
- 右：ステータス`SCAN: ACTIVE`（小さなシアン点 + モノスペース小文字）
- 下に細い区切り線（`rgba(255,255,255,0.08)`）

## 9. スキャンステージ（最重要）

### 9.1 フレーム

`.scan-stage` として、縦横比 1:1.3 程度のグラスパネル。
- 背景：`rgba(20, 30, 50, 0.4)` + `backdrop-filter: blur(12px)`
- 枠：外側に**二重のヘアライン**（1つ目：白 4%不透明、2つ目：シアン 15%不透明、2px離す）
- 角：8px 角丸
- 四隅に小さなL字ブラケット（8px、シアン発光、装置っぽさの指標）
- 上端右に `SCAN ID: HERO_01` モノスペース 9px
- 下端左に `RENDER v0.3` モノスペース 9px

### 9.2 アバター（ローポリ3Dシルエット）

画面中央に、現代日本の中学生男子の**斜め後ろ姿（3/4 back view）**、胸上。

**描画仕様（SVG ポリゴン）**：
- 体型：肩幅があり首が細い、痩せ型
- 髪：短め、後頭部がメインで見える、少し跳ねる
- 服：制服のブレザー襟とシャツの白襟（または黒パーカー）
- 見える顔パーツ：耳の一部、頬のライン（輪郭のみ）、まゆげの先端
- **顔は描き込まない**（将来の差替え前提）

**ローポリ表現**：
- 各部位を5〜12個の三角形・多角形で構成
- 各ポリゴンは微妙に色が違う（ベース色 ± 5%）
- ハイライト面はシアン寄り、シャドウ面はマゼンタ寄り
- 輪郭はなし（色の差分で面を見せる）
- 全体色：ダークネイビー基調（#1a2540 〜 #2a3a60）

**配置**：
- ステージ中央、下辺から 80% の高さまで占める
- 背後に楕円のオーラグラデ（シアン→透明）

### 9.3 スキャン光線（静的モックでは固定位置）

- **形**：水平線（または斜め15°下がり）、太さ3px、長さはステージ幅の120%
- **色**：中央はシアン `#5fb9ff` 不透明度 0.9、両端は透明へグラデ
- **発光**：`filter: drop-shadow(0 0 12px #5fb9ff)` と `box-shadow`を多段
- **位置**：アバターの胸の高さ（ステージ縦の中央よりやや下）
- **動き（v0.3静的版では表現しない）**：本実装では上→下にスイープ、端で折り返し

### 9.4 粒子バースト（光線と体の交点）

光線とアバター輪郭の交差位置に、**粒子が飛び散っている瞬間**を描く。

- 交差点：6〜8箇所（肩の両端、胸中央、腕）
- 各交差点から**3〜7個の小粒子**を斜め上下に放射
- 粒子色は**八徳8色からランダム**（バリエーションが煌めきを作る）
- サイズ：2〜4px、円または4角形、発光あり
- 粒子には微小な尾（短い直線）を付けると躍動感が出る

### 9.5 ステータス数値の浮遊

アバターの左右に、**八徳の現在値が星のように浮かぶ**。

- 右側：VRB 60, LOG 45, WIS 70, ART 50（上から縦配置）
- 左側：VIT 40, VAL 35, WIL 75, HUM 55
- 各数値の表示形式：
  ```
  [徳コード 9px, 徳色, letter-spacing 0.2em]
  [数値 28-32px, display書体, 徳色, 発光]
  [漢字1文字 8px, opacity 0.4]
  ```
- 数値と徳コードの間に**小さなアイコン**（◆/◇/◉/❋/▲/▶/▼/◎ 等）
- 数値の下に**細いライン**（徳色、幅は数値の1.2倍、opacity 0.3）
- アバター輪郭から**細いリーダーライン**（0.5px、徳色、opacity 0.2）が数値へ伸びる ※星座的表現

### 9.6 中央ステータスパック（アバター下）

アバター下〜ステージ底部に、**LEVEL と TOTAL VIRTUE を特大表示**。

```
  [LEVEL]                      [TOTAL VIRTUE]
   14                               412
```

- LEVEL：左寄せ、シアン、60-72px、display書体
- TOTAL VIRTUE：右寄せ、金色 `#ffd54a`、60-72px、display書体
- ラベル（`LEVEL`, `TOTAL VIRTUE`）：9px モノスペース、letter-spacing 0.25em

### 9.7 下部装飾

ステージの下端付近、**スキャン進捗バー**のような装飾。

- 横長のプログレスバー（外枠：ヘアライン、中身：シアン→マゼンタのグラデ、62%）
- ラベル `NEXT SCAN` 左、`18:42` 右（モノスペース）

## 10. 八徳詳細カード（2列×4行）

スキャンステージの下。各カードは以下の構造：

```
┌────────────────────┐
│ [VRB] 文          │
│                    │
│  60                │
│  ─────             │
│  +6 MO   MAX 70    │
└────────────────────┘
```

- 背景：`rgba(255,255,255,0.04)` + `backdrop-filter: blur(8px)` (グラスモーフィズム)
- 枠：徳色 30% 不透明度、1px
- 角：10px
- 内側に**徳色のうっすらしたグラデ**（上から下へ、最上部で 10% 不透明度から透明へ）
- 左上：徳英語コード（16-18px、display書体、徳色）
- 左上右隣：漢字（10px、opacity 0.5）
- 大きな数値：36-44px、display書体、モノスペース混合可、text-shadow で発光
- 数値下に**細いアンダーライン**（徳色、2px、70%幅）
- 最下部に月次差分と最大値を小文字で
- **+が大きい徳**（月次+10以上）は背景のグラデを強めて目立たせる

月次差分の色：
- `+10以上`：徳色で太字 + 小さな↑記号
- `+1〜9`：徳色の通常色
- `+0`：グレー（`#566174`）
- **マイナス表示はしない**（3原則の"減点なし"）

## 17. エフェクト・粒子の指針

### グロー（発光）
- **発光は惜しまない**。重要な数字や徳色の要素には必ず `text-shadow` か `box-shadow` を重ねる
- 例：`text-shadow: 0 0 16px var(--v-wil), 0 0 4px var(--v-wil);`

### グラスモーフィズム
- パネル背景：`rgba()` で 3〜10% の透明度
- `backdrop-filter: blur(8-20px) saturate(140%)`
- 枠線は1px、白4%不透明度
- 疑似要素 `::before` で白ハイライト上端を 1px 引く（ガラスの厚み感）

### 粒子
- 背景の星：固定位置、20-30個、1-2px、opacity 0.3-0.8
- 交差点の粒子バースト：SVGで静的描画、各色からランダム選択
- 粒子に微小な尾を付けると躍動感が出る

### グラデーション
- 徳色グラデ：徳色30% → 徳色0%（縦方向）でカードに奥行き
- CMYグラデ：シアン→マゼンタ、またはシアン→イエロー（スキャンバーや区切り線）
